# Отключение рекламной подмены контактов

Статус: выложено на latitudo.ru по прямому разрешению пользователя «выкладывай».

По согласованию с пользователем отключена подмена телефонов и почты при рекламных
переходах. Обычные контакты регионов остаются прежними. Общая функция
`ndShouldReplaceContacts()` в `local/init.php` возвращает `false`; её используют
обработчики HTML и условия выбора контактов обоих шаблонов, включая старые
проверки источника рекламы и `utm_medium=cpc`.

Сбор UTM, cookies, определение рекламного визита `ndIsUtmVisit()` и код передачи
меток в формы/CRM не менялись. Подменные контакты из базы не удалялись.
Ключ кеша шоурумов изменён на `contacts-original-v1`.

## Состав и откат

46 изменённых PHP-файлов перечислены в `tools/contact-replacement-manifest.json`.
Там же указан локальный временный каталог с исходными версиями всех файлов.
35 файлов находятся в `/local`, 11 — в игнорируемом Git каталоге `/include`.
Для последних сохранён отдельный проверяемый патч
`tools/contact-replacement-include.patch`: обычная выкладка только `/local`
будет неполной. Изменения `.gitignore` и `nd-sale-list.css`, существовавшие до
начала задачи, не относятся к этой работе и не изменялись.

## Проверки

- PHP 8.2, `short_open_tag=1`: синтаксис всех 46 изменённых файлов и проверочного скрипта.
- `tools/test-contact-replacement.php`: 90 изолированных отрисовок трёх шаблонов
  (контакты нового дизайна и региональный подвал обеих тем), пять регионов,
  шесть вариантов UTM, включая отсутствие меток и отдельный `utm_medium=cpc`.
  Проверены обычные телефонные ссылки, отсутствие подменных номеров и обычная почта
  в шаблоне контактов; отдельно — обработчики HTML, новый ключ кеша,
  сбор UTM и восстановление старой рекламной cookie.
- Поиск не выявил оставшихся прямых условий подмены по источнику или `cpc`
  в `/local/templates` и `/include`.
- `git diff --check` по изменённым файлам `/local` прошёл.

Это не полная проверка приложения: локальный `newdesign-latitudo` отвергает
HTTP-соединение, процессы Apache/PHP/MySQL не запущены. Старый адрес
`latitudo-newdesign.loc` не разрешается, а `.osp/apache/httpd-standalone.conf`
из старой инструкции отсутствует. Рабочие сервисы, заявки, письма и CRM
в ходе тестов не запускались.

## Перед выкладкой

Требуется отдельное разрешение пользователя. Сначала восстановить полноценную
локальную проверку страниц обоих дизайнов с метками и без них, затем сверить
текущие серверные версии всех затронутых файлов (особенно `/include`) и подготовить
коммит и откат. Применять к актуальным серверным включаемым блокам только точечные
изменения условий, не перезаписывая контент старой локальной копией. После выкладки
нужен сброс соответствующего кеша контактов/регионов и проверка пяти регионов,
шапки, подвала, выбора города, контактов, шоурумов и блоков связи на страницах.

Modern Web Guidance: плагин установлен и включён, SKILL.md прочитан. Поиск по
ссылкам телефона/почты и anchor href не нашёл подходящего специального руководства;
разметка ссылок, CSS и браузерный JavaScript не изменялись.


## Результат выкладки

Цель подтверждена: vip125.hosting.reg.ru, u0916578,
`/var/www/u0916578/data/www/latitudo.ru`.

Серверные `/local` совпали с исходными локальными версиями; 11 файлов `/include`
оказались новее. Их актуальные версии сохранены в Git коммитом `142ee0e`,
и правки условий перенесены поверх них без замены новых текстов старым контентом.
Эти 11 файлов теперь отслеживаются Git. Коммит отключения — `31806e4`;
уточнение изолированного теста — `708a609`.

Все 46 исходных SHA-256 сверены перед записью, все итоговые SHA-256 проверены
после записи. PHP 8.2 сервера подтвердил синтаксис и 90 изолированных отрисовок.
В тест добавлен DOCUMENT_ROOT и строгая обработка предупреждений после обнаружения
неподключённого блока тизеров в изолированном окружении; повторная проверка прошла.

Очистка кеша news.list сначала встретила конкурентно созданные посетителями файлы.
Кеши news.list, news.detail, catalog.element и catalog.section затем успешно
отделены атомарным переименованием и удалены; проверены страницы после очистки.

20 живых запросов: главная без меток, главная с yandex/cpc, контакты после рекламного
перехода без метки в URL и компания с utm_campaign — для каждого из пяти регионов.
Везде обычные контакты, подменных номеров и latitudo-info@yandex.ru нет.
Сохранение UTM-cookie подтверждено. Ещё четыре запроса после очистки: каталог,
раздел террасной доски, акции и компания Москвы — также прошли.
Отчёты сохранены локально в tools/contact-deploy/live-check.json и extra-check.json.
Реальные заявки, звонки и письма не отправлялись. Полный локальный HTTP-прогон
по-прежнему не выполнялся; поведение страниц проверено на рабочем сайте после
разрешённой выкладки. Старый дизайн проверен изолированными шаблонами, не полноценным
браузерным сценарием.

Откат кода: версии 46 файлов из `142ee0e`; перед откатом сверить отсутствие новых
правок на сервере и затем очистить соответствующий кеш. Рабочая база не менялась.
Скачанный точный снимок также находится в tools/contact-deploy/before.tar;
актуальный манифест с путями и коммитами — tools/contact-replacement-manifest.json.
