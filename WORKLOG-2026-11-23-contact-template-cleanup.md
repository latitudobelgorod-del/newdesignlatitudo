## Проверки и ограничения

- PHP 8.2 с включёнными короткими PHP-тегами: синтаксис 46 подготовленных файлов.
- 552 пары изолированных отрисовок «до/после»: все 46 файлов, шесть ID регионов
  (пять основных и дополнительный), обычный и рекламный визит.
  В рамках фикстур вывод совпал без учёта пробельных символов и HTML-комментариев.
  Проверка использует заглушки API Битрикса и не проверяет реальные вложенные
  компоненты, данные базы, CSS, браузерный JavaScript или интеграцию сайта целиком.
- Для этих фикстур значения подменных контактов пустые; отдельно прежний строгий
  `tools/test-contact-replacement.php` с заполненными подменными значениями
  подтвердил 90 отрисовок, сохранение UTM и выключение подмены на latitudo.ru.
- `git diff --check` по файлам задачи в обоих локальных репозиториях прошёл.
- В 46 готовых шаблонах больше нет `PODMENA`, `ndShouldReplaceContacts` и условий
  `utm_medium == cpc`.

Во время проверки исправлен случай с удалением тела старого `if` без фигурных
скобок в подвале: условие удаляется целиком, чтобы оно не захватило следующую
инструкцию. В финальных проверках расхождений нет.

Полный локальный HTTP/браузерный прогон не выполнялся. Результаты сравнения —
`tools/contact-cleanup/verification.json`. Вызовы проверки:

```powershell

```

Modern Web Guidance установлен и включён; ранее прочитанный SKILL.md и поиск

не внедрялись. PHP-Parser использован только как локальный инструмент разбора,
зависимость на сайты не добавляется.

## Подготовка к отдельной выкладке

Патчи: `tools/contact-cleanup/ru.patch`, `org.patch`, `easy.patch`.
Манифест исходных и готовых SHA-256: `tools/contact-cleanup/manifest.json`.
Точные скачанные оригиналы и готовые файлы находятся в каталогах `before/after`
каждого сайта внутри `tools/contact-cleanup/`. Эти данные позволяют подготовить
откат без старых локальных копий.

Перед выкладкой получить отдельное разрешение, заново сверить хеши серверных
файлов, сохранить изменения в соответствующих репозиториях, подготовить откат,
применить только файлы своего сайта, очистить затронутый кеш и проверить живые
контакты с рекламными метками и без них. Пакет latitudo.org имеет собственный
путь `bitrix/templates`, его нельзя применять к `/local` latitudo.ru.
