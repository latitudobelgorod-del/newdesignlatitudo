# Фид «Товары и услуги» для Яндекс Бизнеса

Инструкция по фиду, который сайт отдаёт в карточки организаций Яндекс Бизнеса
(блок «Товары и услуги» в Яндекс Картах и Поиске).

Дата: 26.11.2026. Автор: подготовлено с Ириной, выложено на прод.

## Зачем это

У Латитудо несколько карточек организаций в Яндекс Бизнесе — по городам.
В каждой есть блок «Товары и услуги», и туда можно загружать прайс-лист в
формате YML. Раньше картинки товаров были одинаковые для всех городов, хотя
склады разные. Теперь у каждого города своя картинка: на фото товара стоит
логотип бренда и подпись склада этого города («СКЛАД в Краснодаре» и т. д.).

Фид собирается для четырёх городов: **Краснодар, Москва, Белгород, Воронеж**.
Состав — продукция **EasyDecking** и **LATITUDO**, 411 позиций в каждом фиде.

## Как это работает — четыре шага

1. **Отметка товаров.** В каталоге у товара стоит галочка «Товары для Яндекс
   бизнес». Только отмеченные товары попадают в фид.
2. **Картинки складов.** Для торговых предложений отмеченных товаров
   генерируются картинки: фото товара + логотип бренда + подпись склада.
   Каждый город — своё свойство.
3. **Сборка фида.** Скрипт берёт полный товарный фид города (его ежедневно
   собирает модуль «Маркет для продавцов»), оставляет только отмеченные товары,
   подставляет картинку нужного города и переупаковывает под требования
   Яндекс Бизнеса.
4. **Расписание.** Cron каждый день пересобирает фиды; раз в неделю добирает
   картинки для новых товаров.

Почему фид собирается из полного фида, а не из базы напрямую: цены, наличие и
ссылки на карточки уже посчитаны модулем по тем же правилам, что и для
Яндекс.Товаров. Один источник — меньше расхождений.

## Шаг 1. Как отметить товар

Админка: **Контент → Каталог (aspro.next) → нужный товар → вкладка «Для
прайс-листа»** (в некоторых карточках — «ДЛЯ ПРАЙС-ЛИСТА»).

В поле **«Список для выгрузки в прайс-лист»** поставить галочку
**«Товары для Яндекс бизнес»**. Остальные галочки («полный товарный фид»,
«фид бренд …») не трогать — они отвечают за другие выгрузки.

Технически это свойство `LIST_PRISE` («Назначение фида», ID 430) с новым
значением `XML_ID = yandex-business`. Сейчас отмечено 267 товаров
(все EasyDecking и LATITUDO).

- Отметка ставится **товару**, а в фид попадают его торговые предложения.
- Товар без предложений тоже попадает — как отдельная позиция.
- Сняли галочку — товар уйдёт из фида при следующей сборке.

## Шаг 2. Картинки складов

Свойства торговых предложений (инфоблок 20):

| Город | Свойство | ID |
|---|---|---|
| Краснодар | `PICTURE_FID_KRD` | 456 |
| Белгород | `PICTURE_FID_BEL` | 457 |
| Воронеж | `PICTURE_FID_VRN` | 458 |
| Москва | `PICTURE_FID_MSK` | 459 |
| Ростов (задел) | `PICTURE_FID_RND` | 460 |

Генератор: `local/tools/nd_feed_pictures.php`.

Что он делает: берёт главное фото предложения (или фото товара, если у
предложения своего нет), уменьшает до 1200 px по длинной стороне, ставит в
левый верхний угол логотип бренда — **у LATITUDO красный домик, у EasyDecking
зелёный листик производителя**, — и пишет жёлтым с мягкой тенью «СКЛАД /
в <городе>». Результат сохраняется как обычный файл Битрикса в `upload/iblock/…`
и записывается в свойство города.

Правила запуска:

- без ключей — заполняет **только пустые** свойства, существующие не трогает;
- `--force` — перезаписывает всё, включая ручные картинки (так 26.11.2026
  заменили старые картинки с «Гарантией до 25 лет»);
- `--since='2026-11-26 14:50:00'` — перерисовать только те файлы, что созданы
  не раньше указанного времени (свои, не ручные);
- `--cities=krd,msk`, `--brand=26365`, `--offer=26346`, `--limit=3`, `--dry-run`.

## Шаг 3. Что внутри фида

Сборщик: `local/feed/business.php` (ключ `--db` включает отметку и картинки).

Отличия от товарного фида — по требованиям Яндекс Бизнеса:

- `<vendor>` обязателен, валюта только `RUB` (в полном фиде `RUR`);
- **одна** картинка на позицию — картинка склада города;
- описание — простой текст без HTML, ссылок, почты и телефонов (правила Карт
  это запрещают), до 3000 символов;
- `shortDescription` до 250 символов (только если описание длиннее);
- нет `param`, `weight`, `dimensions`, `vendorCode` — Бизнес их не читает;
- товары без наличия помечаются `available="unknown"`;
- лимиты Бизнеса: 10 000 позиций и 15 МБ — у нас 411 позиций и около 0,6 МБ.

Состав: только товары с отметкой. Цена — за штуку, как на карточке.

Файлы пишутся атомарно (сначала `.tmp`, потом переименование), поэтому Яндекс
никогда не прочитает недописанный файл. Права 644, отдаются как `text/xml`.

## Как часто обновляются

Сервер живёт по московскому времени.

| Что | Когда | Чем |
|---|---|---|
| Полные товарные фиды городов | ежедневно около 07:00 | модуль «Маркет для продавцов» |
| Фид Бизнеса, Краснодар | ежедневно 08:15 | cron |
| Фид Бизнеса, Москва | ежедневно 08:16 | cron |
| Фид Бизнеса, Белгород | ежедневно 08:17 | cron |
| Фид Бизнеса, Воронеж | ежедневно 08:18 | cron |
| Картинки складов для новых товаров | по понедельникам 08:00 | cron |

Сборка Бизнеса идёт после полных фидов, поэтому цены и наличие в карточках
всегда свежие.

Логи: `/var/www/u0916578/data/logs/business_feed.log` и
`/var/www/u0916578/data/logs/feed_pictures.log` (появляются после первого
запуска по расписанию).

## Как запустить вручную

С сервера, из каталога сайта:

```bash
cd /var/www/u0916578/data/www/latitudo.ru

# один город (с отметкой и картинками склада)
/opt/php/8.2/bin/php local/feed/business.php --code=krasnodar --db

# посмотреть, что получится, ничего не записывая
/opt/php/8.2/bin/php local/feed/business.php --code=krasnodar --db --dry-run

# картинки для новых товаров
/opt/php/8.2/bin/php local/tools/nd_feed_pictures.php

# картинки заново для всех (заменяет и ручные)
/opt/php/8.2/bin/php local/tools/nd_feed_pictures.php --force

# отметить товары брендов / снять отметку
/opt/php/8.2/bin/php local/tools/nd_business_marker.php
/opt/php/8.2/bin/php local/tools/nd_business_marker.php --unmark
```

У московского прайс-листа файл называется `latitudo_full.xml`, у остальных —
`<код>_latitudo_full.xml`; скрипт выбирает сам.

## Как подключить в Яндекс Бизнесе

В каждой карточке организации: **О компании → Товары и услуги → Источник →
«Вручную, из файла» → YML-фид** и вставить адрес города из таблицы выше.

- Новый прайс-лист заменяет прежний.
- Обновления с сайта подтягиваются автоматически.
- В профиле Карт показывается примерно 500 позиций (ограничение Яндекса —
  300 КБ на карточку), но поиск по товарам работает по всему фиду.
- Фото товара в Бизнесе должно быть не меньше 320×240 — у нас 500×500 и выше.

## Как проверить, что всё живо

```bash
# статус и размер
curl -sI https://krasnodar.latitudo.ru/upload/feed/business-feed-krasnodar.yml

# валидность XML и число позиций
/opt/php/8.2/bin/php -r '$x=simplexml_load_file("https://krasnodar.latitudo.ru/upload/feed/business-feed-krasnodar.yml"); echo count($x->shop->offers->offer), PHP_EOL;'
```

В админке: товар → вкладка **«Торговые предложения»** → колонка
**«Картинка фида <город>»** — там видно, что стоит у предложения.

## Если что-то не так

| Симптом | Причина и что делать |
|---|---|
| Товара нет в фиде | нет галочки «Товары для Яндекс бизнес», либо товар неактивен, либо у него нет цены |
| Картинка без подписи склада | у предложения пустое свойство города (новый товар) — запустить генератор вручную |
| Картинка старая / чужая | была сделана вручную раньше; перезаписать: `nd_feed_pictures.php --force` |
| Фид не обновился | смотреть лог; проверить, собрался ли полный фид города в `bitrix/catalog_export/` |
| Фид отдаёт 404 | файла нет в `upload/feed/` — запустить сборку |
| В кабинете старые данные | Яндекс подтягивает фид не мгновенно, обычно в течение часа |

## Ограничения и известные нюансы

- **Ростов** не собирается: свойства под него есть (ID 460), но в карте городов
  скриптов его нет. Включение — добавить город в `CITIES` в
  `nd_feed_pictures.php`, в `$cityPropMap` в `business.php` и строку в cron.
- **Семь товаров без торговых предложений** (пергола, комплект мебели, пять
  аксессуаров) идут в фиде с обычным фото: картинки складов живут в свойствах
  предложений. Если нужен и им склад — понадобятся такие же четыре свойства в
  товарах.
- У части предложений на сайте **одно и то же фото**, поэтому картинки
  получаются одинаковыми; различать можно подписью (например, длиной).
- Ручные картинки затираются только явным `--force`; обычный запуск их бережёт.
- Состав фида меняется в админке — после снятия/постановки галочки дождитесь
  ближайшей сборки или запустите скрипт вручную.
