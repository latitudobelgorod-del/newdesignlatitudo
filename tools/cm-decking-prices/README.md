# Сверка цен СМ Декинг с прайсом Cottage Mode (11.11.2026)

1. `nd_cm_dump.php` — на проде (`~/nd_cm_dump.php`, только чтение): товары и ТП бренда 23345, цена BASE за шт,
   единицы, UNIT_KOEF. `php ~/nd_cm_dump.php > cm_site.json`, файл положить рядом со скриптами.
2. `cm_match.py` — разбор прайсов (первая вкладка, РРЦ) и сопоставление названий сайта со строками прайса,
   «+10%» за цвет из последней колонки. Пути к прайсам — в начале файла (папка `Desktop\Прайс на Cm Decking`).
3. `cm_xlsx.py` — собирает «СМ Декинг — сайт и новый прайс <дата>.xlsx» в той же папке.

Цена на сайте хранится за штуку; за м²/п.м = цена × UNIT_KOEF. Садовый паркет в прайсе — за упаковку 11 шт.
Цены на сайте этими скриптами НЕ меняются.
